# 部落纪元 UI 与地图设计指南

> 来源：2026-08-30 调研整合（像素 UI 原则 / 游戏界面设计规范 / 游戏地图设计方法 / 像素字体生态），
> 结合《叫我大掌柜》等放置模拟经营案例拆解与对本项目 src/ui、src/style.css 的差距分析。
> 用途：后续 UI/地图迭代的决策依据与检验标准。

---

## 一、调研要点（来源摘录）

### 1. 像素画游戏 UI 最佳实践（百家号《如何设计像素画游戏UI？》2025-05）
- **首要目标：清晰地向玩家传递信息并提供易于理解的交互方式**。装饰服从信息。
- 文字：选择/设计小尺寸下依然清晰可辨的**像素字体**；避免过于花哨、难读的字体。

### 2. 游戏界面 UI 设计规范（百度文库）
- **清晰性与可读性**：文本简短、字号合适、行距字距合理、**信息层级分明**、避免信息过载。
- **一致性与可预测性**：同类控件和交互全局一致，玩家凭记忆即可快速找到。

### 3. 游戏地图设计方法（百度文库）
- **导航性与可读性**：清晰一致的符号系统（颜色/轮廓/图标全图统一，禁止不同区域不同标准）；视觉引导（色彩、地形线条引导注意力，不让玩家依赖复杂提示）；关键路径通过**自然线索**显现。
- **信息层级**：地图分层呈现，主次分明。

### 4. 像素字体生态（猫啃网 / CSDN Fusion Pixel 指南）
- **Fusion Pixel Font（缝合像素字体）**：开源，8/10/12px 三档，中日韩完整支持——中文像素 UI 首选。
- **Zpix 最像素**：免费可商用，紧凑但偏旁明确、结构清晰，独立游戏常用。
- 中文像素字体稀缺，**易读性**（偏旁明确、结构清晰）是选型第一标准。

### 5. 放置模拟经营案例（《叫我大掌柜》拆解，B 站）
- 放置经营的核心驱动是**即使不看屏幕也能成长**，UI 要做的是：让玩家每次回来**一眼看到"现在可做的事"**（点击/研究/建造入口的突出、红点/高亮导引）。

## 二、现状差距分析（对照以上原则）

### UI（src/style.css / index.html / main.ts 渲染）
| # | 差距 | 违反原则 |
|---|------|---------|
| U1 | **无像素字体**：system-ui 直接套用，像素风只存在于 canvas 场景，DOM 面板是"普通网页感" | 像素 UI 识别度 |
| U2 | **资源无图标**：全文字 chip，`名称 数量 速率` 一长串，扫视慢 | 视觉层级/扫描性 |
| U3 | **数字非等宽**：每秒刷新时数字宽度抖动 | 稳定性/可读性 |
| U4 | **面板无结构**：工坊内 expedition/buildings/recipes/queue 四个区块平铺，仅靠 h2 小字分隔；族人面板与神迹塞在同一面板 | 信息层级 |
| U5 | **按钮无主次**：放任发展/导出/导入/重开同一视觉权重，"保存"这种高频动作不突出 | 一致性/引导 |
| U6 | **缺少"可做之事"导引**：可研究技术只在图谱里静置，无脉冲/高亮；低食物无警示 | 放置类核心要求 |
| U7 | **反馈弱**：hover 态稀疏（按钮无 hover、行无可点暗示），研究/分配的可点感弱 | 可发现性 |
| U8 | 移动端只有 980px 单列，字体/间距/按钮触区未调 | 适配 |

### 地图（src/ui/worldmap.ts）
| # | 差距 | 违反原则 |
|---|------|---------|
| M1 | **区域无名称标注**：除发源地外所有区域名要点击才知道，违反"识别而非回忆" | 导航性 |
| M2 | **区域无边界轮廓**：可点区域完全靠命中测试，视觉上不存在"区域"概念 | 符号系统缺失 |
| M3 | **状态无颜色编码**：未解锁/可远征/当前文明在静态图上无区分（除红圈） | 符号一致性 |
| M4 | **当前文明红圈对比弱**：#e86a4a 与区域金圈 #d9a24a 同为暖色系，远看混同 | 颜色对比 |
| M5 | **装饰与信息倒挂**：海洋波纹/经纬网格/地形色斑的细节噪音高于功能信息（区域/名字），玩家注意力先被装饰捕获 | 信息层级 |
| M6 | **无图例**：地形色斑含义（沙漠/森林/草原/苔原）无处解释 | 可读性 |
| M7 | 色斑 alpha 0.5 叠在 land 上，五类地形对比度低，远看成一团 | 颜色对比 |
| M8 | 无缩放/拖动，960×560 固定画布，小屏被裁 | 可用性 |

## 三、改进方案（分级）

### A 级：快见效（纯前端/样式，不改数据与玩法）
1. **像素字体落地**：本地化 Fusion Pixel 12px（WOFF2 自托管，web-font），标题/数字用 12px，正文 14px 可保持系统字体（中文长文阅读）；`font-variant-numeric: tabular-nums` 修数字抖动
2. **资源 chip 图标化**：每资源 16×16 内联像素图标（emoji 不行，要统一像素风格），名称+图标+数量+速率排版成两段（`@ 木头 42 (+0.6/s)`），满仓变红保留
3. **工坊分区标题**：expedition/buildings/recipes/queue 各加小节标题行（小图标+文字+数量），族人面板与神迹拆开或加分隔线
4. **可做之事导引**：有可研究技术时线头 `line-hint` 改金色脉冲动画；食物低于安全线资源条闪红；研究完成瞬间记事面板标题闪一次
5. **按钮层次**：primary（研究/保存类）+ normal + danger 三档样式统一，topbar 导出/导入收进「菜单」，重开标 danger
6. **hover/聚焦全量补**：按钮、行、卡片统一 hover 提亮 10%；可点击元素加 `cursor:pointer` 完整性自查
7. 面板 h2 加左侧 2px 彩色竖条（面板内分区识别），面板标题与内容间距统一

### B 级：中期（1-2 轮迭代）
8. **营地场景与 UI 联动**：camp canvas 随季节/事件变色温（夏绿冬白暮光），顶栏加当日事件图标；camp 顶部叠一层资源速览条挂接
9. **世界地图信息优先重绘**：
   - 区域边界线（柔和细线）绘制全区域轮廓，hover 高亮该区域（thick+亮色）
   - 6-8 个区域名小号像素字 + 半透明深色背衬，恒定可见
   - 当前文明改白圈+内红点双色标记，保证与任何底色对比
   - 未解锁区域整体降明度 15%（disabled 视觉），可远征区域边缘金色虚线脉动
   - 海洋波纹/经纬网格 opacity 降一半，色斑 alpha 提到 0.65 + 轮廓微描
   - 右下角图例（4-6 色斑 + 符号说明），右上角「归位」按钮（回到当前文明视角）
10. **保存系统 UI**：导出/导入合成「存档」菜单（modal），显示最终保存时间与游戏天数；重开二次确认加「真的放弃这个纪元吗」
11. **技术图谱细节**：线头加小图标（🔥/🪓 像素图标），展开线加左侧线身竖线（树状联结感），节点可用时边框外发光（box-shadow 金色）

### C 级：长期方向
12. **像素视觉系统统一**：1px 双色描边面板（外深内浅）、像素斜面按钮（亮上暗下 1px）、四角切角装饰；全站图标集（20-30 个 16×16，火/木/石/陶/铜/锡/青铜/斧/窑/屋…）
13. **地图三级结构**：世界（简略，现有）→ 区域详情图（新 canvas，per-region：该区域内的地形/矿点/河流，营地画在上层）→ 营地（现有）
14. **可访问性**：色盲安全配色（红绿信息改红蓝或加形状差异）、键盘导航（tab 顺序+Enter 触发所有按钮）、字体缩放不动布局

## 四、检验清单（每次 UI 改动后自查）

### 启发式自查（改编自 Nielsen 10 项，对照项目）
- [ ] **状态可见**：资源/技术/队列状态 1 秒内能从固定位置读到；速率与存量在同一行
- [ ] **识别非回忆**：区域名、资源名、技术效果都在界面上可见，不依赖记忆
- [ ] **一致与标准**：同类控件全局同款（按钮三档、面板一格式、颜色语义全站统一）
- [ ] **可做之事突出**：当前可研究/可建造的数量 ≥1 时，1 秒内能被发现（高亮/脉冲/红点）
- [ ] **用户控制**：弹层可关闭（×/合上/ESC）、重开有二次确认、无不可逆单点操作
- [ ] **美学极简**：每屏装饰（波纹/网格/描边）不抢功能信息；可关 decorative 元素（如世界地图网格）
- [ ] **防错**：资源不足的按钮禁用并说明原因（技术节点已做），远征/建造给确认行

### 任务测试（验收标准）
- [ ] 新开档 30 秒内：看懂四面板各自是什么（族人=分配、图谱=研究、工坊=造东西、记事=世界动态）
- [ ] 3 秒内能找到"研究一个技术"的入口（图谱可用节点 + 高亮）
- [ ] 3 秒内能找到"分配族人到工作"的入口
- [ ] 世界视图 5 秒内：认出当前文明位置、找到至少 2 个其他区域名
- [ ] 手机宽度（≤980px）所有面板可滚动、按钮可点（触区 ≥ 40px）

### 像素/字体自查
- [ ] 全站像素图标与 canvas 场景风格一致（同色板、同描边）
- [ ] 数字不抖动（tabular-nums）、速率格式统一 `+x.xx/s`
- [ ] 中文正文 12px 像素字仍可读（不行就降级 14px 系统字，宁可不像素）
